# Projet Sell4All – Exploration de données avec Python

## Présentation

Ce projet a été réalisé dans le cadre de la sélection YouCode. Il consiste à explorer, analyser et nettoyer les données clients de Sell4All afin de les préparer pour une future utilisation dans un projet d'intelligence artificielle.

## Étapes suivies

* Installation de Miniconda, Jupyter Notebook, Pandas et Matplotlib.
* Chargement et exploration du fichier CSV.
* Analyse des données (statistiques et visualisation).
* Nettoyage des données (suppression des doublons et des dépenses inférieures à 10 €).
* Export des données nettoyées dans un nouveau fichier CSV.

## Fonctionnalités développées

* Lecture d'un fichier CSV.
* Affichage des informations du jeu de données.
* Calcul de la moyenne et de la médiane.
* Visualisation des dépenses par pays.
* Nettoyage des données.
* Export des données nettoyées.

## Difficultés rencontrées

* Installation de l'environnement Python.
* Prise en main de certaines fonctions de Pandas et Matplotlib.

**Solutions :** utilisation de la documentation officielle et de tutoriels pour comprendre les fonctions utilisées.

## Mode d'exécution

### Prérequis

* Miniconda
* Jupyter Notebook
* Pandas
* Matplotlib

### Installation

```bash
conda install jupyter pandas matplotlib
```

### Lancement

```bash
jupyter notebook
```

Ouvrir le fichier `exploration.ipynb` puis exécuter les cellules dans l'ordre.
